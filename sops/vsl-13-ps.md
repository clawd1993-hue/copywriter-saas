# VSL Section 13 SOP — P.S.

> **When to load:** VSL Section 13 (the FINAL section, after the CTA).
> **What it does:** the last thing they read — restate the dream + the method + a final nudge. If someone ONLY read the P.S., they'd still want to buy.
> **Output:** a P.S. (max 3 sentences), pushed to the "P.S." card. This completes the VSL.
> **Pulls from:** Step 3 Desires + Step 7 Method.

## Opening framing (say this, in your own words)
*"Final one — Section 13: the P.S. This is the last thing they read, and a lot of skimmers jump straight here. So it has to stand on its own: the dream, the dead-simple how, and one last reason to move now."* Then write it.

## Grounding (pull from the board — never invent)
1. **The #1 desire** ← Step 3 Desires — the thing they want MOST.
2. **The method, compressed** ← Step 7 — the 3 steps in ONE sentence.
3. **Urgency / consequence** — the real urgency from the offer (the Section 11 / CTA deadline, price rise, or spots) OR the cost of not acting.

Also read **the VSL so far** — echo the dream + method already established (compressed), and reuse the real price/urgency from the CTA. Don't introduce anything new.

## The formula (a scaffold — write it tight and human)
> "P.S. — Remember, **[dream outcome]** is **[timeframe]** away. All you need to do is **[method compressed — the 3 steps in one breath]**. **[Urgency / consequence of waiting.]**"

## How to run it (write → push straight to the card → celebrate the finish)
The P.S. card is **editable**, so DON'T ask permission — write it and push straight to the card. Per the output contract, do NOT reprint it in the chat.
1. Open with the framing above (a line or two).
2. Write the P.S. — **max 3 sentences.**
3. **Immediately PUSH it** wrapped in `<<<PUSH>>>` … `<<<END_PUSH>>>`. Short confirmation FIRST (visible), then the markers.
4. This is the LAST section — the visible line should **celebrate the whole VSL being done**, not tee up a next section, e.g.: *"🎉 That's it — your full VSL is done, all 13 sections on the board. Scroll it top to bottom; it reads as one letter now. Nice work."*

### Push content format (renders clean on the card)
```
P.S. — [dream outcome, timeframe]. All you do is [method compressed]. [Urgency / consequence].
```

## Rules
- **Maximum 3 sentences.**
- Must restate the **dream** AND the **method** (compressed).
- **End with urgency or emotional consequence.**
- Reuse the real price/urgency already in the letter — don't invent new ones.
- 3rd-grade words.

## Quality test
If someone ONLY read the P.S. and nothing else — would they still want to buy? If not, rewrite until it stands alone.

## Quality gate
- [ ] Restates the #1 dream (← Step 3) and the method compressed to one sentence (← Step 7).
- [ ] Ends on real urgency or the consequence of waiting (reused from the offer, not invented).
- [ ] Max 3 sentences, 3rd-grade level, stands alone.
- [ ] Closing chat message celebrates the finished VSL (last section — no next-section tee-up).
