# Webinar Section 11 SOP — The Pitch (The Stack)

> **When to load:** Webinar Section 11 (right after Product Overview names the flagship). The stack begins.
> **What it does:** reveal the core one-by-one WITH dollar values — value visibly piling up. Picks up straight off §10's "here's everything you get…"
> **Output:** the core stack (flagship + 🧠/🌍 components, with values), pushed to the "The Pitch" card.
> **Pulls from:** Step 8.1 — the flagship (from §10) + the 🧠 + 🌍 core component bullets (each: name + built-in even-if + dollar value).

## Opening framing (say this, in your own words)
*"Now Section 11: the Stack. §10 named it — now we reveal everything inside, one piece at a time, each with a value, so the worth piles up right in front of them. Then a trial close before we add bonuses."* Then write it.

## ⭐ Apply the TANGIBLE FLAGSHIP RULE (lead the stack with the flagship as a real, valued thing)
Lead the stack with the **flagship as Deliverable #1 — a tangible, named thing** (the roadmap/blueprint/program, NOT a vague promise), and give it the **biggest anchor value.** THEN the 🧠/🌍 components.
- **🚗 Flagship (Deliverable #1):** *"First, you get the complete [Flagship] — a step-by-step [roadmap/program] that takes you from [start] to [dream]. (Value: $X — the biggest)."* A concrete thing, not "you'll finally…"
- **🧠 component (Deliverable #2):** *"Then you get [Name] — so you can [outcome], even if [objection], which means [payoff]. (Value: $X)."*
- **🌍 component (Deliverable #3):** *"And you get [Name] — so you can [outcome], even if [objection], which means [payoff]. (Value: $X)."*

Reveal each **conversationally in sequence (First… / Then… / And…)** — value visibly piling up. Not a robotic list. Use the exact names + values from Step 8.1; the components follow §5's belief order (🧠/🌍 in whatever order your board has them).

## Spoken example (match this voice)
> "First, you get the complete [Flagship] — the full day-by-day roadmap, so you're never guessing what to do next. That alone is worth $[X]. Then you get [🧠 component] — so you can [outcome], even if [objection]. That's another $[X]. And you get [🌍 component]…"

## How to run it (write → push straight to the card → tweak or move on)
Editable card, direct-push, don't reprint in chat. Solo.
- PUSH wrapped in `<<<PUSH>>>` … `<<<END_PUSH>>>` (short confirmation first).
- End the copy on a **trial close** + *"and it doesn't stop there…"* (the hand-off into Bonuses).
- Visible line: *"Done — your Stack's in the card. Tweak it there, or ready for Section 12 (Bonuses)?"*

## Rules
- **Flagship leads as a tangible, valued Deliverable #1** (Tangible Flagship Rule) — then the 🧠/🌍 components.
- Each piece carries a **real dollar value** (values pile up — they feed the §14 price anchor).
- Conversational sequence (First/Then/And), **not a robotic list.**
- Use exact names/values from Step 8.1; components in §5's order.
- End on a trial close → "doesn't stop there" (→ Bonuses).
- Spoken tone, 3rd-grade.

## Quality test
Does each piece land as *"that alone is worth it"* AND quietly kill a doubt? Is the flagship a concrete thing (not a vague promise), and is the value visibly stacking?

- [ ] Flagship leads as a tangible, named Deliverable #1 with the biggest value (Tangible Flagship Rule).
- [ ] 🧠/🌍 components revealed in sequence, each with Edwards formula + value (from Step 8.1).
- [ ] Values visibly pile up; conversational, not a list.
- [ ] Ends on trial close + "doesn't stop there" → Bonuses.
