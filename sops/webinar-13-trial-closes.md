# Webinar Section 13 SOP — Trial Closes (the ANCHOR cluster, right before price)

> **When to load:** Webinar Section 13 (right after Bonuses, right BEFORE the price reveal).
> **What it does:** the emotional peak of yeses. A cluster of *"If all this did was…"* closes stacked so they're nodding hard — THEN the price lands soft.
> **Output:** 3–4 laddered trial closes, pushed to the "Trial Closes" card.
> **Pulls from:** Brunson technique (pure persuasion). Wins pulled from **Step 8** (a core component's outcome, a bonus's payoff, the dream ← Step 3).

## Opening framing (say this, in your own words)
*"Now Section 13: Trial Closes — the anchor cluster right before the price. These are little 'if all this did was X, would it be worth it?' questions where the only honest answer is yes. Stack 3–4, get them nodding, then we reveal the price and it feels easy."* Then write it.

## How to write the cluster
Write **3–4 laddered lines**, each: *"If all this did was **[ONE specific win from the offer]**, would it be worth it?"*
- Pull each win from **Step 8** — a core component's outcome, a bonus's payoff, or the big dream (← Step 3).
- **Ladder them** — build from a concrete near-term win up to the big dream.
- Each must be a **near-guaranteed internal "yes"** — if they could reasonably say no, soften it.
- Then hand into price: *"So let me add everything up for you…"*

## Swipe list (Brunson) — for the cluster
- **Anchor (this cluster):** *"If all this did was [benefit], would it be worth it?"*
- *"Can you imagine if that happened to you?" · "Can you see yourself [result]?"*

## Spoken example (match this voice)
> "So let me ask you a few quick questions. If all this did was get you your first paid client in the next month — would it be worth it? If all it did was let you finally charge what you're worth without your voice shaking — worth it? And if all it did was turn photography from your expensive hobby into something that actually pays your rent — would that be worth it? …Yeah. So let me add it all up for you."

## How to run it (write → push straight to the card → tweak or move on)
Editable card, direct-push, don't reprint in chat. Solo.
- PUSH wrapped in `<<<PUSH>>>` … `<<<END_PUSH>>>` (short confirmation first).
- End handing into price: *"So let me add everything up for you…"*
- Visible line: *"Done — your Trial Closes are in the card. Tweak it there, or ready for Section 14 (Price)?"*

## Rules
- **3–4 laddered "if all this did was…" closes**, wins from Step 8, building to the dream.
- Every one = a **near-guaranteed yes** (if they could say no, soften it).
- **No price here** — this sets up §14.
- Hand into price.
- Spoken tone, 3rd-grade.

## Quality test
Could they honestly answer **no** to any of them? If yes, rewrite that one — a trial close only works if the answer's basically guaranteed.

- [ ] 3–4 "if all this did was [win], worth it?" closes, laddered to the dream.
- [ ] Wins pulled from Step 8 (real offer outcomes), each a near-guaranteed yes.
- [ ] No price; hands into §14.
