# Webinar SOP — THE 3 SECRETS (one template, powers Sections 6, 7 & 8)

> **When to load:** Webinar Sections 6 / 7 / 8 — the belief-breaking core AND the teaching heart, where the sale is actually made *by giving real value.* This ONE template runs 3×.
> **Which secret am I writing?** The current section tells you: **Section 6 = Secret #1 (🚗) · Section 7 = Secret #2 (🌍) · Section 8 = Secret #3 (🧠).** Pull THAT one secret from the 3 Secrets Intro (§5) — in the order 🚗 → 🌍 → 🧠. Write **only that secret's** full segment (don't do all three).
> **Pulls from:** **Step 6** (the secret — outcome/without/even-if) + **Step 5** (the mechanism it teaches, the secret's "using…") + Step 3 (for the failure/objection) + **you** (the proof). *(NOT Step 7 — that's the VSL's compression.)*

## Opening framing (say this, in your own words)
*"Now [Secret #N]. This is a teaching section — the belief breaks because they SEE it work and actually LEARN something usable, not because we argued. I'll state the secret, tell the epiphany story, teach one real nugget, prove it, kill the old belief, and lock the new one in."* Then write it.

## The 6 beats (in order)
1. **State the secret** ← §5 full formula: *"Secret #n: how to [outcome] — without [failure] — even if [objection] — using [mechanism]."*
2. **Epiphany Bridge story** *(your own — the one unlabeled, creative beat)*: backstory → the wall *(you believed [failure ← the "without"])* → the epiphany *(you found [the mechanism])* → the plan → the conflict (messy middle) → the win → the transformation. **Weave a light DEMO into the plan/win** — show the mechanism actually working.
3. **★ TEACH IT — deliver REAL value (NEVER skip this):** actually teach **ONE usable nugget** tied to this secret's mechanism — enough that they could go do it themselves — and show/point to the framework. Then the **continuation tie:** *"you'll go deeper on this inside the [program/workshop] — and to do it fast, [their shortcut: an AI tool / the templates + prompts inside]."* This is what makes it a **teaching** webinar, not a pitch. *(A `[SCREENSHARE: show the X framework]` production cue is fine here — it's a real presentation.)*
4. **Proof** ← **you provide:** 2–3 others like them → a specific result. *(If they haven't given proof, write a believable placeholder clearly marked to swap — never fabricate as if real.)*
5. **Disrupt the old belief** ← the **[failure]** + **[objection]:** name what they've been trying and **why it structurally can't work** (not an insult — a structural reason).
6. **Reinforce the new belief (undeniable) + trial close** → bridge into the next secret (or, after Secret #3, into the offer).

## Gather (per secret — straight from §5 / Step 6)
- **Outcome / dream** ← the secret's outcome (Step 6)
- **Mechanism** ← its "using [x]" ← the **Step 5 solution**
- **Failure (the "without")** ← Step 6 ← Step 3
- **Objection (the "even if")** ← Step 6 ← Step 3
- **Proof** ← you provide

## How to run it (write → push straight to the card → tweak or move on)
Editable card, direct-push, don't reprint in chat. Solo (unless the section needs their proof — then ask for it first, briefly).
- PUSH wrapped in `<<<PUSH>>>` … `<<<END_PUSH>>>` (short confirmation first).
- Visible line: *"Done — Secret #[n]'s in the card. Tweak it there, or ready for Section [next]?"* (After Secret #3: hand into Section 9, the Transition.)

## Rules (the ones that make or break the teaching heart)
- Write **only the ONE secret** for the current section (#1=🚗, #2=🌍, #3=🧠). Don't merge all three.
- **★ Every secret MUST deliver real value (beat 3)** — teach one usable thing, then tie to the program/continuation. **No value = it reads as a pitch, not a teach.** Each secret teaches its OWN distinct nugget — don't repeat the same lesson across secrets.
- Every beat except the **story + teach** traces to §5/Step 6 (state, disrupt) or **you** (proof). Don't invent outcomes Step 6 doesn't support.
- **Disrupt = a structural reason the old way can't work** — never argue, never insult.
- **Each secret ENDS IN ITS OWN PROOF** (there's no standalone Proof section in a webinar).
- End each with a **trial close** → bridge to the next.
- Spoken tone, 3rd-grade; name mechanisms (concept), not the branded product name (that's §10/11).

## Quality test
After it: (a) does the matching objection feel **DEAD** — dissolved by story + proof, not argued? AND (b) did they actually **LEARN something usable** (real value delivered, not just claimed)? If either is no, rewrite.
