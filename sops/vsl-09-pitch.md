# VSL Section 9 SOP — The Pitch

> **When to load:** VSL Section 9 (after Product Overview).
> **What it does:** the offer reveal — "here's exactly what you get." Reveal the 3 core deliverables, each with its name, its built-in "even if" objection-kill, and its dollar value.
> **Output:** the 3 core deliverables (Edwards formula + values), pushed to the "Pitch" card.
> **Pulls from:** Step 8.1 — the 3 core deliverables (they map to Method steps 1-3).

## Opening framing (say this, in your own words)
*"Now Section 9: the Pitch. Section 8 made them believe the opportunity is real — this is where we show them the literal thing that delivers it. 'Here's exactly what you get.' Three core pieces, each one killing a doubt as it reveals what they're getting, each with a value."* Then write it.

## What it is
The offer reveal. Present the 3 core deliverables one by one — each carries its **name**, its built-in **"even if"** (which kills an objection in the same breath), and its **dollar value**. Section 8 made them believe; this section shows them the literal thing that delivers it.

## Grounding (pull from Step 8.1 — never invent)
- The **3 core deliverables** ← Step 8.1 (name + built-in even-if + dollar value). Reveal them **in order** (they map to Method steps 1-3).
- If Step 8 assigned dollar values, use them exactly. If a value is missing, propose a believable one (it feeds Section 10's total-value math) and flag it lightly so they can adjust.

Also read **the VSL so far** — open on Section 8's hand-off, and don't echo Section 8's macro belief-breaks verbatim (those were the MACRO promise; these are the MICRO proof — the specific deliverable that kills a specific objection).

## The format (a scaffold — reveal it like showing someone the goods, not reading a slide)
> Here's exactly what you get:
>
> **[Deliverable 1 Name]** — [what it is] so you can [outcome], even if [objection], which means [payoff]. *(Value: $X)*
>
> **[Deliverable 2 Name]** — [what it is] so you can [outcome], even if [objection], which means [payoff]. *(Value: $X)*
>
> **[Deliverable 3 Name]** — [what it is] so you can [outcome], even if [objection], which means [payoff]. *(Value: $X)*

The deliverables already carry the persuasion — each built-in "even if" kills a real objection while revealing what they get (e.g. "even if you've never sold a thing online"). Let each land conversationally.

## How to run it (write → push straight to the card → tweak or move on)
The Pitch card is **editable**, so DON'T ask permission — write it and push straight to the card. *(Overrides the usual "always ask" rule.)* And per the section output contract, do NOT reprint the deliverables in the chat.
1. Open with the framing above (a line or two).
2. Write the 3 core deliverables (name + Edwards formula + value).
3. **Immediately PUSH it** wrapped in `<<<PUSH>>>` … `<<<END_PUSH>>>`. Short confirmation FIRST (visible), then the markers.
4. Visible line — the fork: *"Done — your Pitch's in the card. Tweak it there, or ready for Section 10 (the Bonuses — where we stack the free gifts on top)?"*

## Rules
- **EXACTLY 3 core deliverables** (one per Method step from Step 8).
- Each uses the **full Edwards formula** (so you can… even if… which means…) — that's the built-in objection-kill.
- **Each gets a dollar value** (these feed the total-value math in Section 10).
- The "even if"s here are the **MICRO** proof (specific deliverable → specific objection). Don't echo Section 8's macro belief-breaks verbatim.
- **Conversational reveal, not a robotic claim list.**
- 3rd-grade words.

## Quality test
Does each deliverable make them think *"that alone is worth it"* AND quietly answer a doubt? If a deliverable reveals what they get but kills no objection — sharpen the "even if."
