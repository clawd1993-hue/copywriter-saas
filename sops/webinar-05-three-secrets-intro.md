# Webinar Section 5 SOP — 3 Secrets Intro

> **When to load:** Webinar Section 5 (start of Part 2 — the belief-breaking bulk). The bridge from Set the Frame into the teaching.
> **What it does:** dive right in → lay out all 3 secrets **IN FULL** → hand into Secret 1. This IS how the method gets introduced (as the 3 secrets), so there's no separate "introduce the method" section.
> **Output:** the 3 secrets stated in full formula (vehicle-first), pushed to the "3 Secrets Intro" card.
> **Pulls from:** **Step 6 Part B — the 3 secrets.** Read the 3 finished full-formula lines and STATE them. *(NOT Step 7 — that's the VSL's move-compression. The clean full-formula lines already live in Step 6.)*

## Opening framing (say this, in your own words)
*"Now Section 5: the 3 Secrets. This is where we lay out the whole path — the 3 things they need to believe, each stated in full. We're not teasing curiosity here; we state each secret completely, vehicle first. Then the next sections teach and prove each one."* Then write it.

## Gather from Step 6 (copy the 3 secret lines AS-IS — don't reassemble)
- **Dream** ← 🚗 secret's outcome
- **🚗 Vehicle:** the whole 🚗 Big Promise line (dream · without failures · even-if "nothing works" · using the new way)
- **🌍 External:** its line (outcome · without [external failure] · even-if [external objection] · using [mechanism])
- **🧠 Internal:** its line (outcome · without [internal failure] · even-if [internal objection] · using [mechanism])

## The fill-in (order: 🚗 → 🌍 → 🧠 — vehicle ALWAYS first)
```
Okay — let's dive right in. How do you actually [dream ← 🚗]? It comes down to 3 secrets.

Secret #1 (🚗 — The New Way): How to [dream] — without [failures] — even if [nothing works] — using [the new way].
Secret #2 (🌍 — [title]): How to [outcome] — without [failure] — even if [objection] — using [mechanism].
Secret #3 (🧠 — [title]): How to [outcome] — without [failure] — even if [objection] — using [mechanism].

Get these 3, and [dream]. Let's start with the first…
```
*(If Step 6 lists 🧠/🌍 in a different order, follow Step 6 — but 🚗 is ALWAYS Secret #1.)*

## How to run it (write → push straight to the card → tweak or move on)
Editable card, direct-push, don't reprint in chat. Solo — no interview.
- PUSH wrapped in `<<<PUSH>>>` … `<<<END_PUSH>>>` (short confirmation first).
- Visible line: *"Done — your 3 Secrets are laid out on the card. Tweak it there, or ready for Section 6 (Secret #1 — where we teach + prove it)?"*

## Rules
- **Vehicle-first ALWAYS** (🚗 = Secret #1). Then 🌍 / 🧠 in Step 6's order.
- Each secret = the **FULL formula** (outcome + without + even-if + using mechanism) — a **method overview, NOT a curiosity teaser.**
- Every piece ← **Step 6.** Nothing sourced fresh, nothing reassembled.
- Name the mechanisms / new way (the **concept**), **not the branded product name** (that's §10/11).
- §6/7/8 then **teach + prove** each secret; this intro just STATES them.
- Spoken tone, 3rd-grade.

## Quality test
Can they repeat the 3 secrets back as one simple path — each already believable because it's stated in full (not a vague teaser)?
