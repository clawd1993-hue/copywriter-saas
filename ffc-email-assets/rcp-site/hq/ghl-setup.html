2 · GHL build (once the sub-account exists)

  1. Sub-account "RCP Previews". Timezone America/New_York. Business name Retirement Class Partners, website retirementclasspartners.com.
  2. Number: buy one local US number (any metro, or a toll-free; toll-free verification is faster than 10DLC if we're stuck).
  3. Custom fields on Contact: slug, assets, state_ok, source, mode (= preview / client), firm, advisor_first.
  4. Inbound webhook (Automation → Trigger "Inbound Webhook"): maps the LP payload → create/update contact, set fields, add tag preview-<slug>, add tag by assets bucket (cold <250k · warm 250–500k · qualified 500k–1M · qualified-hi 1M+).
  5. Workflow "Preview setter" triggered by tag preview-*: - Wait 20s (feels human). - Send SMS = §3 message 1. - Hand the conversation to Conversation AI (bot prompt = §3) with "book Michael's 5-min call" as the goal and the calendar link as the only CTA. - Nudges: 24h and 72h if no reply, then stop. - Any inbound from a client-* tagged contact → the real client flow (later).
  6. Notification: every new preview contact → Michael's Telegram/email with slug + phone. Every conversation where the AI flags "sounds like a retiree, not an advisor" → human handoff to Michael.
  7. Test with Michael's own number on /for/dennis-okeefe/ before the first email goes out.

3 · Preview-mode setter script ⚡ draft

Identity rule: until a firm signs, the setter is Retirement Class Partners, never "[Firm]". We're showing the advisor what his retirees would get, so the voice is the concierge, but the sender is us.

Message 1 (auto, 20s after submit)

Hey [First], it's the Retirement Class concierge from Retirement Class Partners 👋 You just registered on the class page we built for [Firm]. This is exactly what your retirees see.

Here's the class link 👉 [SAMPLE LINK]

Real quick, where are you based? Just want to make sure the class applies to you.

Then the real flow, same wording as the client version (FUNNEL-FLOW.md §4.2–4.6): bridge → assets → timeline → motivation → mirror → confirm. The advisor answers as himself or plays a retiree; either works.

Watch-gate, preview version (24h)

Hey [First], did you get a chance to look at the class? Doesn't matter if not. Here's what you've seen so far: registration → instant text → qualification on assets and timeline → the link. For a real retiree, the next message books them straight onto your calendar.

That's the whole machine. Want to see what it looks like running under your name, with your calendar on the end of it? Michael walks you through it in 5 minutes: [MICHAEL 5-MIN LINK]

If they reply anything like "who is this / what is this"

It's Michael's team at Retirement Class Partners. You opened the preview page we built for [Firm] and registered on it, so you're getting the same texts a retiree would. No spam, this is the only sequence. Want 5 minutes with Michael to see the rest? [LINK]. Or reply STOP and I'll close it out.

If they ask about cost / how it works

Short version: you record a 45-min class once, we run it to [City] retirees with $500k+, this concierge qualifies every registrant and books the real ones onto your calendar. For the pilot there's no setup fee and no retainer. Michael covers the exact structure on the call: [LINK]

If they sound like an actual retiree (not the advisor)

Thanks for your interest. This page is a preview we built for [Firm] and the class isn't running yet. If you'd like to be told when it is, reply YES and we'll pass your details to [Firm]. (Flag to Michael. Do not continue the qual flow. Do not send a calendar link.)

Hard rules: no performance claims · no advice · STOP = stop · never claim to be [Firm] · one question per message.

4 · Wiring already in the template

  • LP posts JSON: {name, first_name, email, phone (E.164), assets, state_ok, slug, source, page} to WEBHOOK, then redirects to ty.html?fn=First&a=<bucket>&ph=<last4>. 4-second timeout so a slow webhook never blocks the redirect.
  • TY reads ph: if present → "Check your phone, we texted (•••) •••-1234, reply to that message." If absent (demo mode) → the old tap-to-text button.
  • Consent line under the button: "By registering you agree to receive text messages and emails about this class from [Firm]. Msg & data rates may apply. Reply STOP to opt out." (For previews the sender is RCP, not the firm; swap to "from Retirement Class Partners on behalf of [Firm]" before go-live if counsel wants it.)
